# J-Space Deep Reasoning 增强

> 来源: j-space-skills (J空间认知套件 v3.2)
> 融合目标: 多步推理模式路由、解释门、深度循环

## 解释门

求解前确定实际问题：
1. 用一句话重述目标
2. 识别有歧义的术语
3. 最多列出两个活解释
4. 找到最小分离观察/反例/澄清
5. 分离解决后才承诺一个解释

> Before the path, choose the world in which the path must be true.

## 七种工作模式

| 模式 | 使用场景 | 记录 |
|------|---------|------|
| AUTO | 例行/低风险 | 仅结果 |
| FOCUS | 一个核心目标/约束需持续 | 焦点核 |
| DEEP | 多步推理/新颖计划 | 桥梁+检查点 |
| DENSE | 解释稳定+有码本+延迟展开测试通过 | 可逆符号 |
| EXTERNAL | 分支/高风险/脆弱状态/需审计 | 账本/大纲/表格/代码 |
| EMPIRICAL | 理论不再区分活假设 | 测试+证据 |
| RECOVERY | 重复/矛盾/漂移/退化 | 最后验证检查点 |

## 深度循环

每个有意义的阶段：
1. **Frame**: 陈述即时子问题
2. **Bridge**: 识别答案成立前必须可用的东西
3. **Derive**: 从已验证状态连接桥梁
4. **Stress**: 寻找反例/边界/竞争解释
5. **Commit**: 写一个带范围的结论
6. **Checkpoint**: 记录后续步骤可依赖的内容

## 顺序检查

不信任先于关键中间步骤出现的结论：
- 什么事实/关系必须先为真？
- 它是独立建立的，还是从期望答案反推的？
- 改变桥梁会改变结论吗？

如果是结论先行的合理化，回退并从证据重建。
